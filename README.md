## Task 1: CGPA Calculator
📁 `Task1_CGPA_Calculator/CGPA_Calculator.cpp`

A console program that calculates a student's semester GPA and overall CGPA.

**How it works:**
- Takes the number of courses, then the grade and credit hours for each one.
- Converts each letter grade (A, B+, C, etc.) into grade points on a 4.0 scale.
- Calculates semester GPA = total grade points ÷ total credit hours.
- Combines it with the student's previous CGPA to get the overall CGPA.

**C++ concepts used:** structs, functions, loops, vectors, input validation.

## Task 4: Banking System
📁 `Task4_Banking_System/Banking_System.cpp`

A console-based banking system with account creation, deposits, withdrawals, and fund transfers.

**How it works:**
- `Customer` class stores the account owner's details.
- `Account` class stores the balance and links to its owner.
- `Transaction` class logs every deposit/withdrawal/transfer so each account keeps a full history.
- A menu-driven interface lets the user create accounts and perform banking operations.

**C++ concepts used:** classes and objects, vectors, pointers, functions.
